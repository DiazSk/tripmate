## How the pick was reached

Three systems were comped first: **A Basalt** (cool graphite / azure), **B Clay** (warm clay / jade),
**C Negative** (warm near-black, near-monochrome, colour reserved for data). The user asked for
"B + C", so **D Kiln** was built as the fusion. The user then rejected D as "muddy and dull", which
was correct and measurable: D inherited Clay's brown card, which composites to `rgb(32,24,20)` — a
12-point spread between channels — and a gold money figure printed on a brown surface is two
neighbouring hues with nowhere to separate. **E Kiln II** moved the ground to Negative's
near-neutral `#121110`; the card composites to `rgb(26,24,22)`, a 4-point spread, and the three data
colours each get clean air while the whole thing still reads warm.
