# Think Like a Top 1% Product Designer

## 1. Design the Feeling First

Before opening Figma, ask: **What should the user feel on this screen?**

Typical emotions: - Home → Inspiration - Search → Confidence - Booking →
Trust - Payment → Security - Success → Relief

## 2. Every Pixel Pays Rent

Every element must: - Inform - Guide - Build trust - Create emotion

If it does none of these, remove it.

## 3. One Hero Per Screen

One screen. One focal point. Everything else supports it.

## 4. Build Visual Silence

Premium interfaces rely on: - Whitespace - Minimal colors - Clean
typography - Restraint

## 5. Create Clear Hierarchy

Guide the eye: 1. Hero 2. Headline 3. CTA 4. Supporting details

## 6. Use Color as a Language

-   Brand = Primary action
-   Green = Success
-   Red = Error
-   Orange = Warning
-   Gray = Secondary

## 7. Typography Creates Hierarchy

Use size, weight, and spacing---not random colors---to communicate
importance.

## 8. Design Systems, Not Screens

Create reusable: - Buttons - Cards - Inputs - Colors - Typography -
Spacing

## 9. Respect Rhythm

Use a spacing scale: - 8 - 16 - 24 - 32 - 48 - 64

## 10. Motion Explains

Animation should confirm actions and guide attention.

## 11. Reduce Cognitive Load

Show instead of explain. Prefer images, icons, and progressive
disclosure.

## 12. Design for Trust

Trust comes from: - Clear pricing - Honest reviews - Consistency -
Professional visuals

## 13. Obsess Over Alignment

Align everything: - Text - Icons - Cards - Baselines

## 14. Design Every State

Include: - Loading - Empty - Error - Success - First-time experience

## 15. Remove Before You Add

The simplest interface that solves the problem is usually the best one.

## 16. The 5-Second Test

Can users answer: - What is this? - What do I do next? - Why should I
care?

## 17. Design for Scanning

Use: - Clear headings - Short paragraphs - Logical grouping

## 18. Polish Is Multiplicative

Quality comes from consistent details, not one dramatic effect.

## 19. Solve the User's Next Question

Anticipate the next decision before the user asks.

## 20. Think Like an Editor

Your goal is not decoration. Your goal is clarity.

# Product Designer's Oath

Before shipping, ask:

1.  Is the purpose obvious?
2.  Is there one focal point?
3.  Can I remove anything?
4.  Does color have meaning?
5.  Does it work in grayscale?
6.  Is spacing consistent?
7.  Can a new user succeed?
8.  Does it build trust?
9.  Are interactions predictable?
10. Does it feel effortless?
